# personal-site-content
My contents on personal site

## Blogs Format
Start with 3 dashes and ends with it:
```
---
title: string
slug: string
dateTimeCreated: JS timestring
dateTimeUpdated: JS timestring
tags: string[]
coverImage: string
---
```
### Images 
Just use:
```
https://raw.githubusercontent.com/Zuiluj/personal-site-content/refs/heads/main/Blogs/assets/<name-of-image>.png

then use as markdown link:
![alt](https://raw.githubusercontent.com/Zuiluj/personal-site-content/refs/heads/main/Blogs/assets/<name-of-image>.png)
```


## Rules
- Do NOT use 1st Heading. It will destroy semantics and will look bad to have if it already has title.
